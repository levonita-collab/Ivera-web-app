# QR Print Index

Master index of all 30 mission QR codes, ready for printing on adhesive sticker paper.

## Notes for printing

- Each QR PNG encodes the value `ivera::{tourSlug}::{missionId}` — this is what the in-app scanner expects.
- The "Manual Fallback Code" is what a tourist can type into the app's "Enter code manually" field if the camera can't read a card (works via `resolveManualCode()` in `src/lib/quests/validateMissionQr.ts`).
- All 30 codes are cross-checked against `supabase/migrations/005_seed_qr_missions.sql` — no mismatches, no missing rows, no duplicate QR values (see verification report).
- This index is generated from `src/data/missions.ts`, `src/data/missions.ru.ts`, and `src/data/tours.ts` — regenerate it if mission data changes.
