## Printing instructions

1. Generate each QR code from the **QR code value** column (text/URL type, any free QR generator)
2. Replace `[  QR CODE HERE  ]` in the card layout with the generated image
3. Print on card stock, A6 or larger
4. Laminate before outdoor use
5. Label the back of each card: "Mission 1", "Mission 2" etc. for easy ordering
6. Keep cards in order — guide reveals them one at a time during the tour
